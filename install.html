Install AIPass

Two commands on a machine you choose. Here is what you need, what changes, and how to check it worked.

What you need

  • Python 3.10 or newer.
  • Claude Code on a Claude plan that includes it.
  • Codex, optional: with its binary on your PATH, install wires it as a second CLI for the same agents.
  • Linux or macOS. On Windows, install inside WSL2.

Linux is the daily platform; macOS runs the full test suite in CI. Full requirements.

Install

  1. Put the aipass command on your PATH. 
    $ pipx install aipass
  2. Run the installer. 
    $ aipass install

    It sets AIPass up in ~/AIPass, checks the machine's health, and ends in a conversation that tells you what your machine still needs. It also sets up BAUD, the phone face; add --no-baud to skip it.

  3. Check it. 
    $ aipass doctor

    Doctor names anything that is off, and aipass doctor --fix cures what it can.

What install changes

Beyond its own folder, install adds hooks and deny rules to your user-level Claude Code settings, a few lines to your shell startup file, and command links on your PATH. It may also set git's pull.rebase and, on Linux, add one npm package for the sandbox. Every change to your Claude Code settings leaves a dated backup first.

Run it in a container

A container keeps AIPass and its agents in a sandbox, apart from the rest of your machine.

$ docker run -it python:3.12-slim bash
# apt-get update && apt-get install -y git
# pip install pipx && pipx ensurepath
# export PATH="$HOME/.local/bin:$PATH"
# pipx install aipass
# aipass install --non-interactive --no-baud

--non-interactive installs with defaults and asks nothing; --no-baud leaves out the phone face. A non-interactive install skips the health check, so run aipass doctor --fix afterwards. Install and sign in to Claude Code inside the container to talk to the agents.

BAUD is optional

aipass install sets up BAUD, the phone face, unless you pass --no-baud. Skip it if you only want the terminal. What BAUD does.

Uninstall

Everything to clean up is on your machine; there are no accounts to close. The README walks through removing AIPass from a project, from the whole machine, or removing a single agent.
