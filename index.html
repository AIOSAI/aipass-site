What you get

Two commands. One project folder. Agents that actually stick around.

Persistent Memory

Agents remember previous sessions, key learnings, and collaboration patterns. Kill the terminal, come back tomorrow, pick up where you left off. No re-explaining.

Agent Coordination

Agents communicate through a built-in mail system. They dispatch tasks to each other, share findings, and work together across your codebase without you playing messenger.

Your CLI, Your Subscription

Runs on your existing Claude subscription — any plan that includes Claude Code. No API keys for core features. No extra costs. AIPass orchestrates, Claude Code does the work.

How it works

AIPass gives your project a scaffold: agent directories, memory files, a routing layer, and a planning system. You bring the project, AIPass brings the infrastructure.

1. Install

pipx install aipass puts aipass and drone on your PATH. aipass install clones AIPass into ~/AIPass, builds its environment, sets up the 18 agents, adds BAUD, the phone face (--no-baud skips it), runs a health check, and ends with the AIPass concierge on screen, greeting you and saying what your machine still needs. From a clone instead: ./aipass install in the repo. You need Python 3.10+, Claude Code on a plan that includes it, and Linux or macOS (Windows through WSL2).

2. Say hi

aipass new builds a new project around a resident manager agent and ends in a conversation with it; aipass init run, inside a directory you already have, does a guided setup and ends with claude open in it. Kill the terminal, come back tomorrow, say hi — your agent reads its memory, knows its role, and picks up exactly where you left off.

3. Scale up

Add more agents with drone @spawn create when your project needs them, or spin up a whole new project around a resident manager with aipass new. Agents coordinate through drone commands and mail.

Bring your own project

AIPass works with any codebase — it's a scaffold, not a product, so you shape it to whatever you're building. It adds a scaffold alongside your existing code; install also adds hooks and deny rules to your user-level Claude Code settings, a few lines to your shell rc, and command links on your PATH.

Start with 1 agent for a side project, or a few for a larger app. The reference implementation runs 18 agents that maintain AIPass itself. 

# One citizen shape: what aipass init run and drone @spawn create make (main parts)
your-project/
  src/your_project/
    your-agent/
      .trinity/             # Passport + memory: sessions, learnings, todos, observations
      .ai_mail.local/       # Mailbox: inbox, sent, deleted
      .aipass/              # Branch prompt: standing instructions, injected by hooks
      apps/                 # Entry point → modules → handlers
      docs/                 # Reference pages, tracked
      docs.local/           # Scratch and research, not tracked
      dropbox/              # Inbound drop: files other agents hand over
      artifacts/            # Birth certificate + files the agent produces
      logs/                 # The agent's own logs
      tests/                # The agent's own test suite
      DASHBOARD.local.json  # One status glance; refreshed before every wake
      README.md             # The page for people; agents use drone @<agent> --help

FAQ

What CLI providers does AIPass support?

Claude Code. AIPass runs it as an official subprocess on your existing Claude plan, any plan that includes Claude Code (Pro, Max, Team or Enterprise). No API keys needed for core functionality.

What platforms does it run on?

Linux or macOS (both tested in CI). On Windows, use WSL2 and install inside it: AIPass then runs as the Linux program CI tests. Native Windows and Git Bash are not tested in CI; the code keeps its Windows paths but nothing proves them. AIPass is a Python package that runs in your terminal alongside your existing development tools.

Do I need all 18 agents?

No. Start with 1. The 18 agents in the repo are the reference implementation that maintains AIPass itself. Your project might need 1 agent for a side project, or a few for a larger app. Scale as needed.

How is this different from CrewAI, LangChain, etc.?

Most agent frameworks focus on task orchestration: define a workflow, run it, get output. AIPass focuses on persistence: agents that live in your project, remember across sessions, and develop expertise over time. It's a workspace, not a pipeline.

Is it free?

Yes. AIPass core is free and open source (MIT). You just need an existing Claude subscription (any plan that includes Claude Code) to run your agents.

Does anything leave my machine?

Memory and mail are files on your machine. Nothing leaves it except what Claude Code itself sends to Anthropic, unless you turn on an outside API or Drive sync with your own keys. The phone face serves on your own tailnet, and the first memory search downloads its small embedding model once.

What is BAUD?

The phone face. BAUD shows the same fleet to a human on a phone, served from your own machine. AIPass is what everything runs on; BAUD is how you look at it. aipass install sets it up with AIPass (--no-baud skips it), and it lives in its own repo, github.com/AIOSAI/baud, whose README covers pairing and security.

How do I uninstall?

No cloud accounts, no external services: everything to clean up is on your machine. The README's Uninstall section walks through removing AIPass from a project, from the machine, or removing one agent with drone @spawn delete @agent_name --retire.
